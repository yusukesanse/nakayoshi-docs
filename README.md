# NAKAYOSHI グループ 運営管理システム 要件定義書

このリポジトリは、NAKAYOSHI グループ運営管理システムの要件定義書（公開版）を GitHub Pages で公開するためのものです。本文は [index.md](index.md) から確認できます。

GitHub Pages 標準の Jekyll テーマ `jekyll-theme-primer` と、CDN（配信用サービス）から読み込む Mermaid（文章で記述した図を描画する仕組み）を使います。本文の章間リンクは公開先に合わせて `.html` で記載しています。ローカルでは対応する `.md` ファイルを開いて読めます。
